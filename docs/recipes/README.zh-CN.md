# 使用案例

[English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

先部署 MuseKnock，选择已有的 Muse 侧边对话，并确认测试通知已送达。 [快速开始](../../README.zh-CN.md#快速开始)

- [接收已关注 X 账号的发帖通知](x-notifications.zh-CN.md) · 使用 iOS 27 上 X 应用的推送，无需注册 X 开发者账号，也不产生 X API 费用。
- [从 iPhone 转发 Gmail 故障提醒](gmail-alerts.zh-CN.md) · 在 Gmail 通知预览中匹配关键词，再向 Muse 发送固定提醒。
- [跟踪 GitHub 仓库的版本发布](github-releases.zh-CN.md) · 从有权配置 Webhook 的仓库直接接收版本标签和发行页面链接。
