# レシピ集

[English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

最初に MuseKnock をデプロイし、既存のサイドチャットを選んでテスト通知が届くことを確認してください。 [クイックスタート](../../README.ja.md#クイックスタート)

- [X でフォローしているアカウントの投稿通知を届ける](x-notifications.ja.md) · iOS 27 の X アプリに届く投稿通知を使います。X の開発者登録や API の利用料は不要です。
- [Gmail の障害通知だけを iPhone から届ける](gmail-alerts.ja.md) · Gmail の通知プレビューに特定の語句があるときだけ、Muse に定型文を送ります。
- [GitHub リポジトリのリリースを追う](github-releases.ja.md) · Webhook を設定できるリポジトリから、リリースのタグと URL を直接受け取ります。
